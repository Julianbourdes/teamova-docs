## Ne Perdez Plus le Fil de vos Suivis

Les actions à prendre vous permettent de capturer les tâches qui émergent pendant vos réunions et de vous assurer qu'elles sont réalisées.

## Créer une Action

Pendant ou après une réunion, ajoutez des actions depuis le panneau de droite de votre session.

<Steps>
  <Step title="Décrivez l'action">
    Saisissez une courte description de ce qui doit être fait.
  </Step>
  <Step title="Assignez-la">
    Choisissez le responsable — le manager ou le collaborateur.
  </Step>
  <Step title="Fixez une échéance (optionnel)">
    Sélectionnez une date dans le calendrier si l'action a une deadline.
  </Step>
</Steps>

## Suivez l'Avancement

Chaque action a un statut que vous pouvez mettre à jour au fil de l'avancement.

<CardGroup cols={3}>
  <Card title="En attente" icon="clock">
    L'action a été créée mais le travail n'a pas encore commencé.
  </Card>
  <Card title="En cours" icon="spinner">
    Le travail est en cours sur cette action.
  </Card>
  <Card title="Terminée" icon="check">
    L'action est terminée. Elle apparaît barrée dans la liste.
  </Card>
</CardGroup>

Les deux participants peuvent modifier le statut de n'importe quelle action — c'est une responsabilité partagée.

## Report Automatique

<Info>
  Quand vous terminez une réunion, les actions encore **en attente** ou **en cours** sont automatiquement transférées à votre prochaine session planifiée. Un badge **Reportée** apparaît pour identifier les éléments reportés.
</Info>

Vous n'avez jamais besoin de recopier manuellement les tâches inachevées — elles vous suivent d'une réunion à l'autre jusqu'à ce qu'elles soient terminées.

## Compte Rendu de Session

Après avoir terminé une session, la page de compte rendu affiche toutes les actions en lecture seule. Vous pouvez revoir ce qui a été discuté et ce qui nécessite un suivi avant votre prochaine réunion.

<Tip>
  Utilisez le compte rendu comme référence rapide avant votre prochain 1-on-1 pour vérifier quelles actions ont été reportées.
</Tip>
