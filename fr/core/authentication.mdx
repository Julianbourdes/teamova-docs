## Connexion SSO

Teamova vous permet de vous connecter avec le fournisseur d'identité de votre choix. Pas besoin de créer un nouveau mot de passe : utilisez un compte que vous possédez déjà.

<CardGroup cols={3}>
  <Card title="Google" icon="google" color="#4285F4">
    Connectez-vous avec votre compte Google personnel ou professionnel.
  </Card>
  <Card title="Microsoft" icon="microsoft" color="#00A4EF">
    Utilisez vos identifiants Microsoft 365 ou Azure AD.
  </Card>
  <Card title="GitHub" icon="github" color="#333333">
    Idéal pour les équipes techniques qui utilisent déjà GitHub au quotidien.
  </Card>
</CardGroup>

## Connexion Simplifiée

<Info>
  Teamova retient automatiquement votre dernière méthode de connexion. À votre prochaine visite, le bouton de votre fournisseur habituel est mis en avant pour vous connecter en un clic.
</Info>

Vous n'avez pas besoin de vous souvenir du fournisseur que vous avez utilisé la dernière fois. Teamova s'en charge pour vous et vous guide directement vers la bonne option.

## Liez Plusieurs Comptes

Vous pouvez associer plusieurs fournisseurs SSO à un seul et même compte Teamova. Cela vous offre une flexibilité totale pour vous connecter.

<Steps>
  <Step title="Accédez aux paramètres de votre compte">
    Ouvrez votre profil et rendez-vous dans la section **Comptes liés**.
  </Step>
  <Step title="Ajoutez un fournisseur">
    Cliquez sur **Lier un compte** et choisissez Google, Microsoft ou GitHub.
  </Step>
  <Step title="Authentifiez-vous">
    Connectez-vous auprès du fournisseur choisi pour confirmer l'association.
  </Step>
  <Step title="Basculez librement">
    Vous pouvez désormais vous connecter avec n'importe lequel de vos fournisseurs liés.
  </Step>
</Steps>

## Mot de Passe de Secours

<Tip>
  Même si vous utilisez exclusivement le SSO, nous recommandons de définir un mot de passe de secours. C'est une précaution utile en cas d'indisponibilité temporaire de votre fournisseur d'identité.
</Tip>

Que vous vous soyez inscrit via Google, Microsoft ou GitHub, vous pouvez à tout moment ajouter un mot de passe classique comme méthode de connexion alternative. Rendez-vous dans **Paramètres > Sécurité** pour le configurer.

## Options de Langue

Teamova est disponible en deux langues. Vous pouvez changer la langue de l'interface à tout moment.

<CardGroup cols={2}>
  <Card title="English" icon="flag-usa">
    Interface complète en anglais.
  </Card>
  <Card title="Français" icon="flag">
    Version française complète de l'application.
  </Card>
</CardGroup>

Pour modifier la langue, rendez-vous dans **Paramètres > Profil** et sélectionnez votre préférence.
